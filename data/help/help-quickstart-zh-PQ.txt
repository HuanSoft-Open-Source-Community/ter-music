端闈樂部 · 先秦文言速覽
========================

端闈樂部者，以 ncurses 為基之端闈樂官也。其聲由 FFmpeg 而出，能容諸音聲制式；
曲帙、珍存、往跡與歌辭之屬，皆在其中。此篇以先秦之語述其大略，用字從繁。

一、啟動
--------
  ter-music                 開端闈樂部
  ter-music <目錄>          開所指之樂目錄
  ter-music play <途徑>     掃目錄而以曲授中樞
  ter-music daemon start    起背景之役，閉端闈而樂不絕
  ter-music --help          示諸令之助

  常用全局之選：
    --debug                 書調試之日誌
    --lang <語ID>           此行用所指之語（如 zh_CN、en_US、zh-PQ）
    --frontend=remote|local 以 D-Bus 御中樞，或於本役中直播

二、端闈之界面
--------------
  F1 主頁    F2 節度    F3 往跡    F4 曲帙    F5 珍存
  F6 信息    F7 語      F8 助覽    F9 退

  其界面分為數格：左為播弄列，右為信息、控御、頻譜、歌辭、黑膠之屬。
  格之大小、有無與位置，皆由局度所定；局度可於 節度 → 界面之局度 中擇之。

三、鍵符
--------
  ↑/↓       擇曲或擇項
  Enter     行今事：播曲、開目錄、入曲帙
  空格      播 / 止
  ←/→       易格之焦，或在控御中擇項
  Tab       易播弄列與曲庫之觀
  O / I     開目錄 / 續目錄
  F         珍存今曲
  C / L     焦於控御 / 焦於播弄列
  Ctrl+L    入或出歌辭定位之制
  + / -     增減聲量
  , / .     退 / 進
  /         求索
  q         退

四、播弄與隊列
--------------
  播弄之制有順播、單曲循環、列循環、隨播、隨循環，兼有依文卷匣、樂集、
  樂者而分者。按 M 或於控御中擇之。
  曲之次者，按 N 而進；前曲按 P。
  a 續今曲於隊列，A 插為次曲；隊列可於播弄列之「隊列」觀中理之。
  迅疾有六檔，自 0.75x 至 3.0x；聲量自 0 至 100。
  汰聲（卡拉OK）有三等：勿汰、微汰、盡汰，所以削居中的人聲；樂聲之布于兩耳間者，
  門控存之。易等沿三十毫秒之坡而化，令出即回其等。惟兩聲並列
  者行之，單聲之曲一仍其旧。於控御中擇「卡拉OK」之鈕按 Enter 則出三等之擇單；
  亦可 CLI 曰 ter-music karaoke [off|soft|full|0-2|cycle]，或 D-Bus 曰
  Control.SetKaraoke / Control.GetKaraoke。此名與逐字歌辭之highlighting、與名
  曰 karaoke 之局度預設，三者非同義。

五、曲帙、珍存、往跡
--------------------
  F4 曲帙：左擇曲帙，右閱其曲。N 新立曲帙，D 刪，R 更名，Enter 閱曲或播曲。
  F5 珍存：主界面按 F 以曲入珍存；D 去之，Enter 播之。
  F3 往跡：Enter 以所擇目錄易播弄列，A 續於隊列，D 刪今項，C 清諸往跡。

六、求索
--------
  於播弄列按 /，入所求之字，Enter 求之；n / N 次合 / 前合，Esc 罷。
  求索惟行於文卷之覽；若在隊列之觀，先按 / 而歸文卷，乃求之。

七、信息之格與信息顯明
----------------------
  信息之格常顯狀態、播弄之制、曲題、樂者、樂集或隊列、制式，以及採樣之率、
  位深、比特之率與編。其諸域由 節度 → 信息顯明 之域掩碼所主：
  格惟用其所能容者（狀態/制/題/樂者/樂集/隊列/制式）；序、途徑、聲量、迅疾
  惟及 CLI/D-Bus。閉其域則行減；閉「制式」則音聲之塊亦隱。
  格面之顯，兼須 節度 → 播弄之度 之「樂集之面（總閘）」與 信息顯明 之「顯面」
  二閘俱開。面之修廣、字集、音程與歌辭行數，惟及 CLI/D-Bus，不及於格。

八、節度
--------
  F2 開節度。左為諸目，右為其項；←/→ 易焦，↑/↓ 擇項，Enter 行或展，Esc 返。
  節度之要目：
    端闈之飾      主題、諸格之前景背景、色之調
    默途          啟時所開之樂目錄
    播弄之度      語、時延、樂集之面、無縫預載、音聲後端、汰聲之等
    播弄之制      默播弄之制與迅疾
    捷鍵          改諸事之鍵；r 復今項，R 盡復，s 存
    遠器          錄 SMB/SFTP/FTP/WebDAV/HTTP 之遠源
    均音          十段增益、預增與預設
    信息顯明      預設、諸域、面、音程與歌辭行數

九、局度
--------
  節度 → 界面之局度 可擇內置諸局；Enter 擇之，E 開局度之器。
  局度之器以分欄之樹定諸格：方向鍵擇格，Tab 循環，[ ] 調寬，{ } 調高，
  | / - 分欄，x 刪，t 易類，c 易色，w 易位，S 存，Esc 返。
  凡幾何、色、未知之格、空洞、重疊與非 guillotine 之舊局，皆自適為強制平鋪。

十、語
------
  F7 開語之度：↑/↓ 擇語，Enter 易之，A 納語包，D 刪用戶之語包，Esc 返。
  內置者三：zh_CN（華文簡體）、en_US（English）、zh-PQ（中文（先秦），應用譯名端闈樂部）。
  用戶之語包以 .tar.gz 納之，其中須有 lang.xml；內置之語不可刪。

十一、往跡與信息
----------------
  F6 信息：關於、府庫之址與許。此頁惟讀。
  F3 往跡：目錄之往來；Enter 易播弄列，A 續隊列，D 刪，C 清。
  F8 助覽：此篇也；/ 求索，n/N 次合，↑/↓ 滾。

十二、離開
----------
  q 或 F9 退。若以 daemon start 起背景之役，端闈雖閉而樂不絕；
  欲止之，行 ter-music daemon stop。

  願端闈之樂，與君相始終。
