端闈樂部 · 先秦文言速覽
========================

端闈樂部者，以 ncurses 為基之端闈樂官也。其聲由 FFmpeg 而出，能容諸音聲制式；
曲帙、珍存、往跡與歌辭之屬，皆在其中。此篇以先秦之語述其大略，用字從繁。

一、啟動
--------
  ter-music                 開端闈樂部
  ter-music <目錄>          開所指之樂目錄
  ter-music play <途徑>     掃目錄而以曲授中樞
  ter-music daemon start    起背景之役，閉端闈而樂不絕
  ter-music --help          示諸令之助

  常用全局之選：
    --debug                 書調試之日誌
    --lang <語ID>           此行用所指之語（如 zh_CN、en_US、zh-PQ）
    --frontend=remote|local 以 D-Bus 御中樞，或於本役中直播

二、端闈之界面
--------------
  F1 主頁    F2 節度    F3 往跡    F4 曲帙    F5 珍存
  F6 信息    F7 語      F8 助覽    F9 退

  其界面分為數格：左為播弄列，右為信息、控御、頻譜、歌辭、黑膠之屬。
  格之大小、有無與位置，皆由局度所定；局度可於 節度 → 界面之局度 中擇之。

三、鍵符
--------
  ↑/↓       擇曲或擇項
  Enter     行今事：播曲、開目錄、入曲帙
  空格      播 / 止
  ←/→       易格之焦，或在控御中擇項
  Tab       易播弄列與曲庫之觀
  O / I     開目錄 / 續目錄
  F         珍存今曲
  C / L     焦於控御 / 焦於播弄列
  Ctrl+L    入或出歌辭定位之制
  + / -     增減聲量
  , / .     退 / 進
  /         求索
  q         退

四、播弄與隊列
--------------
  播弄之制有順播、單曲循環、列循環、隨播、隨循環，兼有依文卷匣、樂集、
  樂者而分者。按 M 或於控御中擇之。
  曲之次者，按 N 而進；前曲按 P。
  a 續今曲於隊列，A 插為次曲；隊列可於播弄列之「隊列」觀中理之。
  迅疾有六檔，自 0.75x 至 3.0x；聲量自 0 至 100。
  汰聲（卡拉OK）有三等：勿汰、微汰、盡汰。其法於 200 Hz–5 kHz 间逐频而较 side
  与 mid 之幅比，削居中相干者；樂聲之布于兩耳間者與偏于一侧之瞬态存焉，故偏侧之
  镲、鼓不復使居中之人聲随原聲漏出。微汰餘约八分贝，盡汰尽去带内居中者；带外两端
  （100 Hz、10 kHz）实测所衰不过 0.25 dB。惟兩聲並列者行之，單聲之曲一仍其旧。
  启之则迟窗长减一（44.1 kHz 下三百八十三样本，约八点七毫秒；诸采样率皆不过十毫秒）；
  启之或于启时 seek，前数毫秒復闻一度，以暖其析窗，微、盡互易则否；止之则约
  三百五十毫秒渐隐，而后逐位直通。易等以三十毫秒为常而化，令出即回其等。
  於控御中擇「卡拉OK」之鈕按 Enter 則出三等之擇單；
  亦可 CLI 曰 ter-music karaoke [off|soft|full|0-2|cycle]，或 D-Bus 曰
  Control.SetKaraoke / Control.GetKaraoke。此名與逐字歌辭之highlighting、與名
  曰 karaoke 之局度預設，三者非同義。

五、曲帙、珍存、往跡
--------------------
  F4 曲帙：左擇曲帙，右閱其曲。N 新立曲帙，D 刪，R 更名，Enter 閱曲或播曲。
  F5 珍存：主界面按 F 以曲入珍存；D 去之，Enter 播之。
  F3 往跡：Enter 以所擇目錄易播弄列，A 續於隊列，D 刪今項，C 清諸往跡。

六、求索
--------
  於播弄列按 /，入所求之字，Enter 求之；n / N 次合 / 前合，Esc 罷。
  求索惟行於文卷之覽；若在隊列之觀，先按 / 而歸文卷，乃求之。

七、信息之格與信息顯明
----------------------
  信息之格常顯狀態、播弄之制、曲題、樂者、樂集或隊列、制式，以及採樣之率、
  位深、比特之率與編。其諸域由 節度 → 信息顯明 之域掩碼所主：
  格惟用其所能容者（狀態/制/題/樂者/樂集/隊列/制式）；序、途徑、聲量、迅疾
  惟及 CLI/D-Bus。閉其域則行減；閉「制式」則音聲之塊亦隱。
  格面之顯，兼須 節度 → 播弄之度 之「樂集之面（總閘）」與 信息顯明 之「顯面」
  二閘俱開。面之修廣、字集、音程與歌辭行數，惟及 CLI/D-Bus，不及於格。

八、節度
--------
  F2 開節度。左為諸目，右為其項；←/→ 易焦，↑/↓ 擇項，Enter 行或展，Esc 返。
  節度之要目：
    端闈之飾      主題、諸格之前景背景、色之調、界面之局度、通體色式
    默途          啟時所開之樂目錄
    播弄之度      語、時延、樂集之面、無縫預載、音聲後端、汰聲之等
    播弄之制      默播弄之制與迅疾
    捷鍵          改諸事之鍵；r 復今項，R 盡復，s 存
    遠器          錄 SMB/SFTP/FTP/WebDAV/HTTP 之遠源（詳十二）
    均音          十段增益、預增與預設
    信息顯明      預設、諸域、面、音程與歌辭行數

九、局度
--------
  節度 → 端闈之飾 → 界面之局度 可擇內置諸局；Enter 擇之。
  同頁「修局度／新局度」可開局度之器。
  局度之器以分欄之樹定諸格：方向鍵擇格，Tab 循環，[ ] 調寬，{ } 調高，
  | / - 分欄，x 刪，t 易類，c 易色，w 易位，S 存，Esc 返。
  凡幾何、色、未知之格、空洞、重疊與非 guillotine 之舊局，皆自適為強制平鋪。
  端闈之明暗：同頁「通體色式」可擇自／明／暗，藏於 config.xml 之
  preferences.appearance_mode（契約十）。自者首幀前先問端闈之底（OSC 11）；
  不答，惟 deepin-terminal 者讀其本題（讀而不寫，至多每二秒察其變；識先
  TERM_PROGRAM，未設乃察祖鏈；他端不讀），次讀 XDG 案牘之 color-scheme
  （隨之運行），次 COLORFGBG、次 TERM 之示，終守舊暗之貌；節度之頁顯其源。
  前端本地 ~/.config/ter-music/appearance-terminals.json 可按端闈覆通體之默
  （節度之頁「本端闈色式」）；所探之明暗屬各前端進程，不書於 config.xml。
  底明則出廠主題與七預設易為明底之安色；君所改之色存，用戶局度惟前景猶等
  預設出廠暗值者乃易（TER_MUSIC_LAYOUTS 如其文而用）。
  端闈能報其見者，去而復歸即自復探；不能者，用同頁「復探端闈之底」。

十、語
------
  F7 開語之度：↑/↓ 擇語，Enter 易之，A 納語包，D 刪用戶之語包，Esc 返。
  內置者三：zh_CN（華文簡體）、en_US（English）、zh-PQ（中文（先秦），應用譯名端闈樂部）。
  用戶之語包以 .tar.gz 納之，其中須有 lang.xml；內置之語不可刪。

十一、往跡與信息
----------------
  F6 信息：關於、府庫之址與許。此頁惟讀。
  F3 往跡：目錄之往來；Enter 易播弄列，A 續隊列，D 刪，C 清。
  F8 助覽：此篇也；/ 求索，n/N 次合，↑/↓ 滾。

十二、遠源
----------
  遠源者，前端之務也。前端列其目錄，逐曲下於本地之藏，乃以藏中之路授核心；
  核心未嘗自開遠方之URL（本地路徑之約見 docs/API_DBUS_en_US.md）。

  於節度→遠器（第六目）立一聯：名、協議（SMB/SFTP/FTP/WebDAV/HTTP，
  以+/-易之）、主機、端口（空則用該協議之默）、用戶名、密碼、
  基途，及依協議而顯之域：
    HTTP/WebDAV/FTP有TLS（https/webdavs/ftps），啟之則有「信自簽之證」；
    SFTP有私鑰、私鑰口令、known_hosts之徑。
  基途不可闕（「/」為伺服之根）；SMB填共享名與可擇之子徑，如music/albums，
  勿用smb:// URL。目錄之徑/URL不必自補尾斜，前端列目錄時自補之。
  TLS為每聯之啟，不以端口為斷：非443之HTTPS，須啟TLS而填其實端口。
  ENTER改域，+/-易協議或TLS，S存，ESC罷。
  端口不在1-65535或基途空者不可存；刪聯先請確認（ENTER刪，ESC留）。

  SFTP驗主機之鑰且fail-closed：須有可讀之known_hosts（聯中所填，否則
  ~/.ssh/known_hosts）且已載其伺服。無默然初信之事；先以
  ssh-keyscan HOST >> ~/.ssh/known_hosts 載之。

  聯之動作單：覽目錄、載此目錄於播弄列、更聯、修聯、刪聯。目錄之覽，↑/↓擇：
  ENTER入所擇之夾（在首行或擇一曲時則載今夾），→亦入所擇之夾，ESC返上層。
  開一夾，則下其夾之音聲之卷（惟此夾之卷，不及子夾）於藏，一次至多二百曲；
  多者示已載若干、共若干。下載行於後臺：其頁示「下載中 done/total，敗 n」，
  主界之狀態行亦然；ESC罷今務。動作單有「罷今務」「復列目錄」「復試敗曲（n）」。

  其限：一遠卷至多1 GiB，一次列目錄至多32 MiB（二十萬條）；連接逾十秒、
  列目錄逾百二十秒、每曲下載逾六百秒則罷。一卷逾限則棄之而他曲續。
  SMB文件名含';'、'!'、雙引號、反斜或制字者不收（smbclient之命令模式），
  宜於伺服端改名。下載隨需而為，無預取。

  藏於$XDG_CACHE_HOME/ter-music/remote/
  （默~/.cache/ter-music/remote/）。遠器之頁示其用量，
  可立上限（默2048 MB，0則不限）而清其未護者；
  正在播、在隊列、在珍存、在往跡者不刪。音卷旁之.lrc亦隨之而藏。

  憑證：聯表為前端之remote.xml（權0600）；密碼以定鹽XOR之流蒙之，非真加密。
  日誌、核心之last_opened_path、曲庫之目錄往跡皆存脫敏之URL，故自往跡復取
  之URL無密碼；有密之伺服宜用聯表。臨時開遠URL，勿以user:password@入之——
  其文見於shell之史與進程之表。

  TUI亦可徑開遠方之URL：
    ter-music -o webdav://host/music/
  所受之scheme：http(s)、ftp(s)、sftp、smb、webdav(s)（dav/davs為別名），
  大小寫無別。
  CLI之play與daemon start --open不受遠方之URL：核心惟播本地之路。

  自動之試所及：HTTP/WebDAV/FTP、FTPS之TLS握手、非443之HTTPS、自簽CA之信、
  401/404、慢速下載之罷，及以假smbclient所驗之SMB。真Samba、真SSH與FTPS之
  數據道未及。

十三、玲瓏之器
--------------
  玲瓏（Linyaps）之容器中，前端不能析離脫之核心，乃請宿主以D-Bus激活之；
  激活不可用者，先於宿主行 ll-cli run cn.org.huansoft.ter-music --
  ter-music daemon foreground。
  容器之中，ll-box ≤ 2.3.5 之冷啟轉發，遇端闈之隊列既滿，
  則重放其已寫之字節，以重出之文攙入端闈之流。應用不能止其寫；容器之內，
  惟逐幀計其入端闈之字節（/proc/self/io 之 wchar），見驟寫或背壓之據，
  或端闈易其修廣，乃一整屏重繪。裸模式之重置亦準此據（或易其修廣），
  endwin+refresh 之兜底須以 TER_MUSIC_TTY_HARD_RESET=1 顯啟（默閉）。
  容器之外不行此事，守衛亦未增節度之鍵、設置之目、用戶可見之開關。
  所闕者：無據之時，不復以時計排重繪；幀微而讀緩者若有損，不即重繪，
  或俟端闈易其修廣、易其視，或復見據而後覆。
  根治在上游：PR #295 已合於 linyaps-box 之 release/2.3（合併之提交 31ddf04，
  2026年11月20日），其轉發於 TryAgain 且 k > 0 時改為消費已寫之字節；所及
  ll-box ≤ 2.3.5。今尚無含此修之發行（最新發行仍 2.3.5），master 亦未載之，
  故裝時宜核所用 tag 果含此修，勿遽謂次版必含。ter-music 次一 Release 擬不發布
  UAB，俟上游之修既出而後發布。TER_MUSIC_TTY_REPAIR_BACKSTOP_MS 者，
  未載於典冊之調參也，惟司已刪之時計兜底；已隨其去，今設之無驗。

十四、離開
----------
  q 或 F9 退。若以 daemon start 起背景之役，端闈雖閉而樂不絕；
  欲止之，行 ter-music daemon stop。

  願端闈之樂，與君相始終。
