ter-music 快速上手
==================

1. 启动
--------
  ter-music [选项] [路径]     直接进入 TUI 界面
  ter-music tui [路径]        显式进入 TUI
  ter-music <命令> [选项]     CLI 模式（详见第 19 节）

  TUI 选项:
    -o, --open <路径>  启动时打开指定音乐目录、音频文件或远程URL
    -d, --debug        启用调试日志（ter-music-debug.log）
    -v, --version      显示版本号
    -h, --help         显示用法
    --frontend=local   迁移期基线：本进程自己出声（默认 remote=交给常驻核心）
    --attach-only      只连接已在运行的核心，没有核心就报错退出
    --bus <名称>       指定目标实例的总线名（默认主实例）
    --lang <语言ID>    本次运行使用该语言（如 zh_CN、en_US、zh-PQ），不写入 config.xml

  运行模型：默认是“常驻核心 + 前端”。TUI 只是前端，声音由核心进程播放；
  没有核心时前端会自动在后台拉起一个（Linyaps 容器内改为请求 D-Bus 激活）。
  核心只播放前端下发的本地路径队列，曲库、歌单、收藏、历史、远程源等内容
  一律由前端持有。TUI 必须在真实终端里运行，不能把输出重定向到管道。

  示例:
    ter-music -o ~/Music
    ter-music -o /path/to/song.mp3
    ter-music ftp://user:pass@host/path/to/music

2. 界面布局
-----------
  主界面由 JSON 分栏树驱动，共 6 种窗格：
    playlist / info / controls / spectrum / lyrics / vinyl
  每个布局是一棵二叉分栏树：分栏节点按 row（左右）或 col（上下）切开矩形，
  叶子引用窗格种类。因此布局天然强制铺满主区域（终端除底部菜单栏外的全部区域），
  不会出现空白、缝隙或重叠；终端缩放时按千分比比例重算。
  旧版自由矩形布局仍可读取：能 guillotine 切割的精确转换；空洞、重叠、越界、
  非 guillotine 的布局会按阅读顺序自动适配，并在重载提示/编辑器中说明，不再拒绝。
  lyrics 与 vinyl 可同处一局：两格都在时，曲目有歌词则两格各画各的；无歌词则
  lyrics 格临时让位、由其余窗格补位，换到有歌词的曲目会自动回来（同一个状态
  轮询周期内，无需切视图或改终端尺寸）。只有 lyrics 时，无歌词的曲目仍在该
  窗格内回退显示黑胶动画（彩色可用时为色块，否则为字符）；布局已有独立频谱
  窗格时，回退动画不再重复画频谱条。
  窗格内容（含信息窗格专辑封面）裁剪在边框以内；窗格过小时只显示背景与边框，不覆盖边框。
  信息窗格按自身宽高自动排布：较宽时元数据与音频参数左右并列、封面居右；
  窄而高时封面在上，元数据与音频依次在下。封面与右边框之间始终留有空列，
  空间不足时自动隐藏封面。
  选择布局：F2 -> 界面外观 -> 界面布局（←/→ 循环，ENTER 开列表）；
  “重新加载布局”可重读布局文件，并报告自动适配数量。
  编辑布局：F2 -> 界面外观 -> 编辑布局 / 新建布局（直接编辑分栏树，
  右侧实时预览；方向键选择，Tab 循环，[ ] 调比例，| / - 分栏，x 删除，
  t 换类型，c 颜色，w 交换，Enter 操作菜单，? 帮助，S 保存，Esc/q 返回）。
  保存写入用户覆盖文件；编辑内置预设即同 id 覆盖，改名用 n 键。
  预设（7 个）：classic / vinyl / karaoke / visualizer / focus /
              stage / neon
  内置文件：/usr/share/ter-music/layouts/layouts.json（源码树 data/layouts/）
  用户覆盖：~/.config/ter-music/layouts.json（同 id 覆盖内置）
  选中状态：~/.config/ter-music/ui-layout（前端本地，不写入 config.xml）

3. 焦点切换
-----------
  C             切换到控制栏
  L             切换到列表区
  Tab/Shift+Tab  切换文件浏览 / 播放队列视图
  （歌词定位模式中 Tab 改为切换歌词来源，见第 10 节）

4. 列表区操作（文件浏览或队列）
-------------------------------
  导航:
  ↑/↓  或  j/k      选择上/下一曲
  Enter 或  Space    播放选中曲目（文件浏览视图里落在目录行时为展开/折叠）

  播放控制:
  n                下一曲
  p                上一曲
  h                显示播放历史弹窗（最近若干条，ENTER 播放，ESC 取消）

  队列管理:
  a                将曲目追加到播放队列
  i                将曲目插入为队列下一首
  d                从队列中移除曲目
  D                清空整个队列
  J                将曲目在队列中下移
  K                将曲目在队列中上移

  歌单与收藏:
  A                将曲目加入自定义歌单（弹出选择列表，需先在 F4 建好歌单）
  F / f            将曲目加入收藏
  O / o            打开音乐文件夹
  I                追加音乐文件夹到当前列表

  搜索与浏览:
  S  或  /         搜索曲目（支持拼音搜索）
  M                切换曲库浏览器
  + / -            音量增 / 减（每档 5%）

  快捷播放模式:
  1                顺序播放
  2                单曲循环
  3                列表循环
  4                随机重复
  5                文件夹顺序

  主界面与子视图都支持鼠标（左键与滚轮）；一次事件只归一个属主，
  要么是当前展开的弹层，要么是指针所在的那块窗格，不会被两处同时处理：
    · 底部功能键栏：点击＝按下该键；滚轮在此无动作（事件仍被消费）。
    · 歌单窗格：点击选中该行并播放（文件树里＝展开/收起目录）；
      滚轮使选中项上下移动一行，搜索结果、播放队列、文件树同样有效，
      且滚轮不会触发播放。
    · 音乐库浏览器（按 M 打开，此时顶替歌单窗格）：点击选中该条并执行
      （深入）；[S]/[R] 行触发扫描/重扫；滚轮移动选中项（与上下键相同）。
    · 控制栏窗格：点击＝按下光标所在的按钮（音量钮与进度行只移焦点，
      与键盘一致）；滚轮在进度行＝快进/快退 5 秒，在音量钮＝±5%，
      在倍速钮＝在预设倍速间切换（首尾循环），其余按钮（含卡拉OK钮，
      它的档位只能从弹层里选）无动作。
    · 歌词窗格：点击＝跳到光标所在那一句；滚轮＝快进到下一句/上一句
      （不会改变歌词定位模式的开与关）。
    · 信息、频谱、黑胶窗格：该处没有定义的动作，事件在此被消费，
      因此不会漏进别的窗格。
    · 子视图侧栏与内容区：点击＝选中并执行（等同回车）；滚轮在指针
      所在那一列移动选中项。设置页按所在分区分别作用于选项列表、快捷键
      列表、远程设备列表；均衡器页只在频带之间移动，滚轮绝不改动增益数值；
      帮助页每次滚动一行。关于视图的内容区是只读文本、语言视图的侧栏只有
      "返回"一项，这两处滚轮只被认领，无位移。高亮跟着指针走：在内容列
      滚动或点击会同时把键盘焦点带到该列。双击/三击没有额外语义，按一次
      单击处理，绝不执行两次。
    · 弹层展开期间（控制栏的播放模式/倍速/音量/卡拉OK菜单、设置页的选项选择器、
      布局编辑器的模态菜单）：滚轮只滚动弹层，无论指针在屏幕何处；点在
      弹层内部即选中并执行该项（多选选择器里＝空格勾选）；点在弹层外部只
      收起弹层，该次点击被吞掉，不会穿透到背后的窗格。设置页选择器在选项
      所在位置展开（首行即选项行、左缘对齐选项文字），靠近边缘时上翻/左翻
      并钳制，完整留在终端内，不压状态行、底部提示行、滚动条与右边框。
    · 文本输入框是模态的（搜索、扫描目录、布局改名、快捷键捕获、数值颜色
      输入），其中的鼠标事件一律忽略，误滚不会弄坏正在输入的文字。
    · 程序不读取鼠标修饰键（按住 Shift/Ctrl 点击与普通点击相同）；只申请
      滚轮上下，横向滚轮与指针移动（悬停）不上报给程序。
    · 右键在指针位置打开上下文菜单：菜单整体钳制在屏幕内（贴边时上翻/左翻，
      不覆盖底部提示条行）。同一时刻只有一个弹层；弹层/菜单展开时右键只关闭
      它并吞掉，不叠加菜单、不穿透。菜单内左键单击即选中并执行，滚轮移动
      选中，子菜单向侧边展开；键盘 ↑/↓/Enter/Esc/→ 可用，其它键关闭并吞掉。
      列表窗格菜单含队列管理、收藏、加入歌单、目录/搜索/播放历史、播放控制与
      页面跳转，并有"切换到文件/队列模式"一条；右键不会播放指针下那一行。
      各子视图（设置/历史/歌单/收藏/帮助/语言）各有本页菜单；信息页只有
      "科乐美流光"一条；布局编辑器右键打开"窗格操作"菜单。队列/历史/曲库行
      在菜单打开后发生变化时，行操作会提示"列表已变化，请重试"并拒绝执行。
      菜单与正在刷新的歌词/频谱/黑胶窗格相交时，窗格刷新会与菜单 backing
      合成后单次上屏，菜单矩形不会被擦掉。

5. 控制栏操作（按C键聚焦后）
-----------------------------
  ←/→              选择控制按钮
  Space            激活按钮 / 打开弹出菜单
  ↑/↓              光标在[音量]上时增/减音量
  ,                后退 5 秒
  .                前进 5 秒
  +/=              增加音量
  -/_              减少音量
  Ctrl+L           进入/退出歌词定位模式，之后用 ↑/↓ 逐行跳到该句时间点

  控制按钮说明:
  [<<]    上一曲
  [>||]   播放 / 暂停
  [>>]    下一曲
  [停止]  停止播放
  [模式]  播放模式（弹出菜单列出当前可用的模式档位）
  [速度]  播放速度（弹出菜单 0.75x / 1.00x / 1.25x / 1.50x / 2.00x / 3.00x）
  [音量]  音量弹出菜单（0-100，步进 5%）
  [卡拉OK] 消人声弹出菜单（不启用 / 人声较弱 / 消除人声；仅立体声生效；切档平滑即时生效，
           声场展开的伴奏被门控保留）
  [进度]  当前播放进度显示

6. 播放模式（共 17 种）
--------------------
  基础模式（始终可用，5 种）:
    顺序播放      顺序播放，列表播完停止
    单曲循环      重复播放当前曲目
    列表循环      列表播完从头开始
    随机一次      随机播放，每曲一次不重复
    随机重复      持续随机播放

  文件夹模式（4 种，文件浏览视图下提供）:
    文件夹顺序 / 循环 / 随机 / 随机重复，作用范围限定在当前目录

  高级模式（8 种，需 SQLite 曲库里的专辑、艺术家标签）:
    专辑顺序 / 循环 / 随机 / 随机重复
    艺术家顺序 / 循环 / 随机 / 随机重复

  按空格打开控制栏的[模式]按钮弹出菜单进行选择。
  在 设置 → 播放模式 中选择默认模式并开启“高级模式”。

7. 功能键（F1-F9）
-------------------
  F1  主页（返回主界面）
  F2  设置（界面外观/布局、路径、播放、播放模式、快捷键、远程设备、均衡器、信息显示）
  F3  目录历史（打开过的音乐目录：ENTER 载入、A 追加到队列、D 删除当前项、C 清空）
  F4  歌单（管理和创建播放列表）
  F5  收藏（查看和管理收藏的歌曲）
  F6  关于（版本和项目信息）
  F7  语言（语言管理：ENTER 切换、A 添加语言包、D 删除；内置 zh_CN、en_US、zh-PQ）
  F8  帮助（本页面，/ 可搜索、↑/↓ 滚动）
  F9  退出前端界面（stop_core_on_exit=1 为缺省，退出时同时终止播放核心；
      设为 0 才只退前端、音乐后台续播，见第 20 节）
  ESC + 1..9 与 F1..F9 等价；q / Q 与 F9 走同一条退出路径。

7.1 自定义按键
---------------
  “设置 → 快捷键”现在是可编辑的动作列表：
    ↑/↓            选择动作
    Enter/空格     捕获新键（Esc 取消）
    r              恢复当前动作的默认键
    R              恢复全部默认键
    s              保存（写入 config.xml；在此之前只改内存）
    ←/Tab          返回菜单侧栏

  除系统保留键外，其余动作都可以改绑：
    - F1-F9：视图/退出功能键
    - q / Q：退出
    - Tab / Shift+Tab：文件/队列选项卡切换
  这些保留动作不会出现在设置页编辑列表中；播放控制、列表/队列、曲库
  浏览器、设置、远程设备以及其他视图动作仍可编辑。

  键位语法（大小写敏感）：
    x、A、7、/      单个 ASCII 可打印字符（空格必须写 space）
    ctrl+a          Ctrl+字母；c/h/i/j/m/z 被终端占用，不可绑定
    up down left right home end pgup pgdn ins del backspace tab btab enter space
    f1 ... f12      命名特殊键
    Esc 与 Ctrl+C 是系统保留键，不可绑定。

  只有被修改的动作会写入 config.xml，例如：
    <keybindings>
      <binding action="track.next" key="]"/>
      <binding action="track.prev" key="["/>
    </keybindings>
  动作 ID 就是 `ter-music keys list` 输出的稳定字符串。
  系统保留动作的覆盖在运行时会被忽略，`ter-music keys check` 会给出警告；
  Config.Set 会拒绝为它们设置新键。
  同一上下文内的冲突会被拒绝：提示会说明原因，原有绑定保持不变。
  改绑某个动作后，它的全部默认别名都会失效，只保留新键。
  不支持：Alt 组合、多键序列（如 gg）、非 ASCII 键。改绑立即生效，
  重启后仍然保持。

8. 曲库浏览器（M）
---------------
  按 M 进入/退出曲库浏览器，数据来自前端曲库 library.db（无曲库时按 M 无效）。
  首页四项：艺术家 / 专辑 / 风格 / 全部曲目，↑/↓ 选择，Enter 或空格进入。
  层级：首页 → 艺术家 → 专辑 → 曲目；首页 → 专辑 → 曲目；
        首页 → 风格 → 曲目；首页 → 全部曲目。
  曲目列表按键：
    ↑/↓        选择曲目
    Enter/空格 播放选中曲目（不在当前列表时先追加，然后退出浏览器）
    a / A      把选中曲目追加到当前播放列表
    ESC        返回上一层（首页按下则退出浏览器）
  首页额外按键：S/s 扫描指定目录，R/r 重新扫描全部根目录，M 或 ESC 退出。

9. 搜索功能
-----------
  在主界面按 S 或 / 键进入搜索模式。
  输入关键词后按 Enter 确认，结果即时过滤显示。
  用 ↑/↓ 选择，Enter 播放。
  按 Esc 取消搜索（正在进行的异步搜索会被中止）。
  支持拼音搜索（如输 "zhou" 可找到 "周杰伦"）。

10. 歌词显示
------------
  优先级：内嵌歌词（FFmpeg/APE 标签）> .lrc 文件 > 无歌词（歌词栏显示黑胶动画：颜色可用时为彩色块，否则为原字符动画；频谱在独立的频谱窗格中始终显示）
  自动加载同目录下的 .lrc 文件。
  内嵌歌词优先显示（ID3/APE 标签中的歌词；识别 lyrics、lyrics-eng、
  UNSYNCEDLYRICS、©lyr 等键）。
  Ctrl+L 进入/退出歌词定位模式：↑/↓ 逐行移动光标并跳到该句时间点。
  本地与远端前端都生效——跳转经播放器门面下发给核心，不再依赖本地进度追踪。
  切换歌词来源：Ctrl+L → Tab（歌词定位模式中）；来源偏好由前端记进曲库。
  歌词窗格显隐由布局预设决定（不是配置项开关）；歌词对齐可在 设置 -> 界面外观 中调整：居左 / 居中 / 居右。

11. CUE 分轨支持
-----------------
  与音频文件同名的 .cue 分轨表自动解析（常见于 FLAC/APE/WV 整轨文件）。
  子曲目在列表中显示 [CUE] 前缀。
  CUE 编码自动检测（可在 设置 → 播放设置 中配置）：
    自动 / UTF-8 / GB18030 / GBK / BIG5 / Shift-JIS

12. 均衡器
-----------
  10 段 ISO 图示均衡器（31Hz - 16kHz）。
  在 设置 → 均衡器 分区中调节：←/→ 选择频段，↑/↓ 调节增益（±12dB），
  ENTER 切换启用；预增益同样限制在 ±12dB。
  按 P 打开独立的“均衡器预设”弹窗（摇滚/流行/古典/爵士/电子/人声/
  重低音/现场/通用平衡/平坦，共 10 组），预设只改频段增益，不动预增益。
  输出侧用 tanh 软限幅，避免叠加增益后的削波失真。

13. 远程播放
------------
  支持 SMB/SFTP/FTP/WebDAV/HTTP 协议。
  在 设置 → 远程设备 中配置连接。
  远程目录由前端列出并逐曲下载到本地缓存，再把本地路径交给核心播放。
  也支持命令行直接传入远程 URL 进入 TUI：
    ter-music ftp://user:password@host/path/
  CLI 的 play / daemon start --open 不接受远程 URL：核心只播放本地路径。

14. 歌单管理
------------
  F4 进入歌单管理。
  支持新建、重命名、删除歌单。
  在主页按 A（大写）将曲目加入自定义歌单。

15. 收藏功能
------------
  选中曲目后按 F/f 添加到收藏。
  F5 查看和管理收藏列表。

16. 专辑封面
------------
  控制区封面由 设置 → 播放设置 的“专辑封面”总开关控制；
  信息窗格封面另有 设置 → 信息显示 的“显示封面”开关，两者都开才显示。
  CLI/D-Bus 的字符封面可为盲文 / ASCII / 半块字符集；TUI 信息窗格与控制区的封面
  使用彩色半块字符绘制（256 色 → 8 色 → 黑白自动回退），以保证字宽与终端
  单元格网格一致。彩色模式用 ▀ 合成两层（前景=上半、背景=下半），█ 仅用于单色回退。
  独立黑胶窗格绘制彩色半块碟面、旋转的封面圆形中心标签与彩色频谱柱
  （标签沿用同一套 256→8→黑白回退）。无颜色、ASCII 或色对预算不足时
  保持原字符动画；封面读取失败时仍绘制彩色碟面与频谱柱，中心为纯深色碟面。
  优先读取音频内嵌封面；否则查找同目录常见封面文件
  （cover/folder/front/album，扩展名支持 jpg/jpeg/png/webp）。
  字符画按需生成：换曲时 D-Bus 的 CoverChanged 信号只通知“封面变了”，
  文本参数为空，真正要画时才经 Info.GetCoverArt 取数（结果按尺寸缓存）。
  启用 D-Bus 时，封面还会以 mpris:artUrl 发布，供桌面媒体组件显示。
  CLI 可直接输出当前曲目封面字符画：ter-music cover [--width --height --charset]

17. 信息窗格与音频后端
-----------------------
  信息窗格显示播放状态/模式、当前曲目元数据、字符封面，
  以及当前音频的技术参数（窗格位置由布局预设决定）：
    采样率、位深、比特率、编码格式
  字段行由 设置 → 信息显示 的字段掩码驱动：窗格只显示它能显示的字段
  （状态/模式/标题/艺术家/专辑/队列/格式），关闭字段后行数收紧，
  关闭“格式”后音频块消失；序号/路径/音量/倍速仅 CLI/D-Bus。
  信息窗格会根据自身宽高在“左右并列”和“封面在上、文字在下”两种排布间切换。
  TUI 封面使用彩色半块字符（非盲文；256→8→黑白自动回退）绘制；
  `ter-music cover`/Info.GetCoverArt 仍按配置的盲文 / ASCII / 半块字符集输出。

  音频后端自动检测优先级：PipeWire > PulseAudio > ALSA
  在 设置 → 播放设置 的“音频后端”中手动切换：
    自动 / PipeWire / PulseAudio / ALSA（下次启动生效）
  “输出时延”项 ENTER 打开 20–250 ms 的弹窗，改动在下次播放时生效。

  设置 → 信息显示 分区：预设、字段、封面同时作用于主页信息窗格与 CLI/D-Bus；
  封面尺寸/字符集、进度样式、歌词行数只影响 `ter-music show` 与 D-Bus 的
  Info.GetDisplay/GetInfo 输出。字段选择器中标“仅 CLI”的项不影响信息窗格。

18. 配置与数据
--------------
  布局：  内置 <prefix>/share/ter-music/layouts/layouts.json；
          用户覆盖 ~/.config/ter-music/layouts.json；
          选中状态 ~/.config/ter-music/ui-layout（前端本地）。
          show_lyrics_panel 已弃用，仅在没有 ui-layout 时作为首次映射提示。
  配置：  ~/.config/ter-music/config.xml   由核心独占写盘（XML 根版本属性写配置
          契约号，当前为 9；历史 "2.2" 文件仍可加载，升级首启迁移后改写为数字）。
          前端只修改自己的配置镜像，再把差异经 Config.Set 交给核心落盘。
  内容：  ~/.config/ter-music/library.db   前端 SQLite 曲库，含曲目元数据、
          扫描根、播放历史、收藏、歌单与歌单曲目、目录历史、临时播放列表。
  队列：  不再有 queue.txt。播放队列由前端扫描内容后分块下发给核心（单块
          ≤500 条：首块 Queue.Set、其余 Queue.Append），核心不落盘队列；
          前端断线重连后会把整表补推一次。恢复播放用的曲目游标由 resume
          会话字段提供，不依赖任何队列文件。
  断点：  上次曲目与进度由核心在换曲时写入配置，前端启动时据此恢复。
          开关是配置项 resume_last_playback（不在设置页列表里），可用
          `ter-music config set resume_last_playback 0` 关闭。
  封面缓存由程序自动管理：/tmp/ter-music-cover-*.jpg
  （按最近使用保留 10 张，退出时清理）。

  首次运行会自动从 v1（config.json + JSON 文件）迁移。

19. 命令行（CLI）
------------------
  ter-music help 打印简短概览；帮助分层如下：
    help | --help | -h              简短概览
    help <命令>                     一级详情
    help <命令> <子命令>            二级详情
    help all                        全量帮助
    <命令> --help                   一级详情（会解析选项的命令：play、
                                    show、daemon、queue、config、lyrics、
                                    track、cover、keys）
    <命令> <子命令> --help          二级详情
  未知的帮助目标以退出码 1 结束。

  帮助文本按终端宽度换行。stdin 与 stdout 都是 TTY 且内容超过一屏时，
  启用内置分页器：空格/PageDown 下一页、b/PageUp 上一页、j/k 逐行滚动、
  g/G 跳到首/尾、q 退出。非 TTY 输出、TERM=dumb 与
  TER_MUSIC_NO_PAGER=1 会直接完整输出，不产生 ANSI 转义序列。

  CLI 本地帮助、错误、表格与提示按以下语言优先级取用：
    --lang > TER_MUSIC_CLI_LANG > 配置 ui_language > LC_ALL >
    LC_MESSAGES > LANG > zh_CN
  --lang 与 TER_MUSIC_CLI_LANG 可写在命令行任意位置。C、POSIX 与空
  locale 视为无偏好，继续使用配置的 ui_language。--lang 指定的语言包
  未安装时会警告并回退 zh_CN。show/track/lyrics/cover 的正文由核心按其
  ui_language 渲染，--lang 只影响 CLI 自身的文案。

  所有子命令都是纯 D-Bus 客户端，默认发给主实例（daemon 或 TUI），
  可用 --bus <名称> 指定次要实例（--bus 写在子命令之后）。

  播放控制:
    play <路径> [--index N] [--mode 模式] [--no-daemon] [--foreground] [--quiet]
      · 有路径：本进程扫描后把本地路径队列分块下发并播放；路径支持 ~
        和相对路径，直接给单个音频文件时精确命中该文件。
      · 无路径且无 --index：继续播放核心当前队列（Control.Play）；
        队列里没有可播曲目时报错。
      · 无路径但有 --index：装载配置的默认音乐目录
        （default_startup_path，其次 remember_last_path 的 last_opened_path），
        下发后从第 N 首开始播（N 从 0 计，指装载内容里的序号）。
      · --mode：队列下发完成后再设播放模式（shuffle 等会就地重排执行顺序）。
      · --foreground：本进程作为前台核心装载并播放，不创建后台实例；
        已有主实例时会被拒绝。
    pause | resume | toggle | stop | next | prev
    seek <+秒|-秒|mm:ss|N%>    相对 / 绝对 / 百分比跳转
    volume [0-100|+N|-N]        查询或设置音量
    speed  [0.5-3.0]            查询或设置倍速
    mode   [名称|0-16]          查询或设置播放模式
    karaoke [off|soft|full|0-2|cycle]  查询或设置消人声档位（cycle 进一步）
      仅立体声生效；档位即时回显，DSP 沿 30ms 斜坡追平；与名为 karaoke 的布局预设、
      逐字歌词高亮不是一回事。

  队列编辑（直接作用于核心的播放队列）:
    queue list [--offset N] [--count N]   分页列出（count 0=默认 200，上限 1000）
    queue append <路径>[,<路径>...]        追加本地文件到队尾
    queue insert <pos> <路径>              在指定位置之后插入本地文件
    queue remove <pos>                     删除指定位置曲目（0 基）
    queue clear                            清空队列
    queue shuffle                          打乱队列（当前曲置首、其余乱序）

  配置读写（复用核心 Config 接口，键名同 config.xml）:
    config get [key]              完整配置 JSON，或按键提取单值
    config set <key> <value>      写单个标量配置（按 schema 类型转换/钳制）
    config reload                 通知核心重载配置文件
    config reset --yes            恢复全部默认配置（必须显式 --yes）

  信息显示:
    show [--json|--watch[=ms]|--one-line|--full|--compact|--preset|--fields
          --cover|--no-cover|--cover-size|--charset|--progress|--no-progress
          --lyrics|--width] [--bus <名称>]
                                  输出当前播放信息（内容取自“设置 → 信息显示”）
    track                         当前曲目的人读信息
    cover [--width N --height N --charset braille|ascii|half]
                                  当前曲目字符封面
    lyrics [--lines N]            默认当前歌词行上下文；--lines N 拉全量带时间戳

  键位（只读，无需核心在运行）:
    keys list [--json]            按上下文列出各动作的生效键位
    keys check [--json]           审计 config.xml 中的键位覆盖

  后台播放进程:
    daemon start [--open 路径] [--debug] [--force]
    daemon foreground [--open 路径] [--debug] [--force] [--no-autoplay]
                                注：核心不扫描目录，--open 只作提示，队列由 play 下发
    daemon stop [--force] [--all] | status [--json] | reload
    daemon restart [--open 路径] [--debug] [--force]

  其他: version | --version | help | help all | --help | tui

  退出码：0 成功；1 参数错误；3 没有运行实例；4 D-Bus 不可用；
          5 实例拒绝或操作失败。

20. 更多技巧
------------
  按 F8 查看本帮助页（帮助页里 / 可搜索、↑/↓ 滚动 3 行）。
  按 h 打开播放历史弹窗，F3 是目录历史视图，两者不是一回事。
  设置中每项都用 ENTER 打开选项菜单（不再需要 +/- 键调节）。
  卡拉OK（消人声）分三档：不启用 / 人声较弱 / 消除人声。它只削弱立体声里居中的
  人声，伴奏与低频高频保持不变；单声道曲目原样播放。切换有三处：主页控制栏的
  [卡拉OK] 按钮弹出菜单、设置 → 播放设置、ter-music karaoke。注意「karaoke」在
  本项目还另指两事——逐字歌词高亮与名为 karaoke 的布局预设——与消人声无关。
  档位存于 config.xml 的 karaoke_mode（0/1/2），重启后自动恢复。
  设置 → 默认路径 分区新增“重新加载配置”“恢复默认设置”两项，ENTER 即执行。
  调整终端大小后界面自动适应。
  q / F9 / Ctrl+C、SIGTERM 与 TTY 断开都收敛到同一条收尾路径，按前端自己的
  配置镜像里的 preferences.stop_core_on_exit 分流（启动时已读盘，设置页的改动
  即时下发核心，退出时不再回问核心）：1（缺省启用）发 Control.Quit 终止播放
  核心——核心先落盘会话/resume 状态再停播退出；0 发 Control.Detach，只关前端
  界面、核心后台续播。两者都仅在该前端确实接入过核心（握手完成、持有 Attach
  令牌）时才发；没接入过的退出不会带走核心。切换：设置页开关“退出时停止播放
  进程”，或 `ter-music config set stop_core_on_exit 0`。多前端时，已接入的前端
  一退即无条件终止核心（=1），不判断剩余前端；local 模式（同进程出声）不受
  影响。随时单独停核心：ter-music daemon stop。
  想让“关掉 TUI 后核心一并退出”：把 config.xml 的
  <preferences><core_exit_when_no_frontend> 设为 1（该键不在设置页，也不在
  Config.Set/`config set` 的键表里）。开启后核心在最后一个前端离开并静默
  10 秒后自行退出。
  与核心断线时界面会自动重连（指数退避），按 R 可立刻重启核心。

21. D-Bus 与 MPRIS / 歌词 API
------------------------------
  核心在会话总线上以 org.mpris.MediaPlayer2.ter_music 发布对象
  /org/mpris/MediaPlayer2，同时提供 MPRIS 与 ter-music 自有接口：
    cn.org.huansoft.ter_music.Info / Control / Lyrics / Queue / Config
  握手看 Info.GetInfo 里的 core.api_version（当前 5；客户端最低要求 4，
  v4 核心只是缺少逐字字段）。

  MPRIS 侧：Rate 是可读写的真实倍速（MinimumRate 0.5 / MaximumRate 3.0），
  LoopStatus 与 Shuffle 会做完整的播放模式切换；OpenUri 明确回 NotSupported
  （加载内容归前端）。

  歌词接口：
    方法：   GetLyrics() -> s（A/B 行快照）
             GetDocument(offset, count) -> s（分页全文）
             SetSource(source) -> b（1=内嵌，2=外置）
    信号：   LyricsChanged(s)
    逐字时间：GetDocument 每行带 end/timing/char_total，逐字 LRC 另有
    chars[] 数组；GetLyrics 带 char_sung/char_total。

  读取当前 A/B 歌词快照：
    gdbus call --session --dest org.mpris.MediaPlayer2.ter_music \
      --object-path /org/mpris/MediaPlayer2 \
      --method cn.org.huansoft.ter_music.Lyrics.GetLyrics

  完整规范：见源码目录 docs/API_DBUS_en_US.md 与 docs/API_LYRICS_en_US.md。
